# Data Attribution

This project uses historical cricket match data downloaded from
[Cricsheet](https://cricsheet.org/), including Indian Premier League match data
in Cricsheet JSON format.

Player names and identifiers present in generated audit and processed datasets
are derived from the Cricsheet match data and the Cricsheet Register. The
Cricsheet Register is made available under the
[Open Data Commons Attribution License 1.0](https://opendatacommons.org/licenses/by/1-0/).
Public use or redistribution of Register data or works produced from it must
provide attribution, identify the applicable license, and preserve relevant
source notices.

Cricsheet is not affiliated with this project and is not responsible for its
processing, ratings, gameplay, or simulations.

The original Cricsheet source files are not relicensed by this repository.
Before redistributing source match files or substantial derived datasets, check
Cricsheet's current terms and preserve any notices supplied with the source
archive.
